# Fly Asset Register

## Current status

No fly image, model, or runtime asset is present in the supplied NeuroFly source folder. The asset is missing or unverified. A static model could support an exhibit view, but the MVP needs an independently controlled proboscis pivot and a documented contact proxy.

## Candidate lead

The implementation planner records a lead: FruitFly Hub credits an adult Drosophila CT-scan model by etainproject under CC BY 4.0 and links to an original Sketchfab listing. This is a lead only. The original listing, current license, public redistribution rights, editable source, mesh, rig, and proboscis movement have not been inspected or verified in this project.

## Functional fallback

If no rights-cleared usable asset passes intake, create a small original or procedural adult-fly-like greybox with separate body, head, legs, and proboscis pieces. Keep the anatomy visually cautious and label simplified anatomy. Only add a proboscis degree of freedom and stable contact proxy needed for the first loop.

## Intake requirements before use in a public build

- Record the creator, source page, asset title, download date, license and URL, attribution text, and permission record.
- Verify redistribution, modification, and public browser embedding rights for the actual runtime file.
- Inspect scale, axes, orientation, origin, meshes, textures, skeleton, pivots, and missing dependencies in Blender and the target browser.
- Confirm the proboscis can extend, hold, and retract without moving the whole head; document the contact proxy and its relationship to the rendered mesh.
- Keep the unchanged source file, runtime export, and credit record separate. Add approved credits before public release.
